MEIRA — A VISUAL DIARY
======================

HOW TO PREVIEW
1. Unzip the folder.
2. Open index.html in a modern browser.
3. Keep the assets folder beside index.html; the page uses relative paths.

WHAT'S INCLUDED
- Responsive cinematic editorial portfolio
- Six photo projects with category filters and detail lightboxes
- Three uploaded vertical videos with playback modals
- About and contact sections
- Reduced-motion support and mobile layout

BEFORE PUBLISHING
- Replace the placeholder contact email hello@example.com with your real portfolio email.
- Review all captions/project descriptions and adjust anything that doesn't reflect your intentions.
- For public hosting, upload the entire folder to a static host (for example GitHub Pages, Netlify, or Vercel).

NOTE
The portfolio uses your supplied media files. Some video previews may take a moment to load because the original videos are included at their uploaded quality.
